# @moonsjs/mcp

MCP server (stdio) untuk framework [**Moons**](https://github.com/moonsjs/docs):
memberi agen AI jalan pintas terverifikasi — tabel route, registry serverFn
(hash), `moons check`, pencarian dokumen konteks framework, dan penjelasan kode
error §15.

Tool: `list_routes`, `get_fn_registry`, `run_check`, `search_docs`,
`explain_error`.

```bash
bunx --package @moonsjs/mcp moons-mcp   # bin `moons-mcp` ≠ nama package → --package
```

- Dokumentasi API: [docs/api/ai-first.md](https://github.com/moonsjs/docs/blob/main/docs/api/ai-first.md)
- Konteks agen: [docs/ai/CONTEXT.md](https://github.com/moonsjs/docs/blob/main/docs/ai/CONTEXT.md)
